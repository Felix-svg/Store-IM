# Store-IM

## Author
Felix Omondi

## Description
This project is a Command-Line Interface (CLI) application for managing inventory. It allows users to perform various operations such as adding, updating, deleting, and viewing items in the inventory. The CLI provides a user-friendly interface for managing inventory efficiently.

## Features
- Add new categories to the inventory.
- List all categories in the db.
- Add new items to the inventory.
- Update existing items in the inventory.
- Delete items from the inventory.
- View details of all items in the inventory.
- View the total cost of the inventory.

## Installation
1. Clone this repository to your local machine.
`git clone https://github.com/your-username/inventory-management-cli.git
`
2. Navigate to the project directory.
`cd Store-IM
`

## Usage
- To start the CLI application, enter the virtual environment by running `pipenv shell`, then navigate to the `lib` directory, and run the following command:
`python3 cli.py`
- Follow the on-screen instructions to perform various operations such as adding, updating, deleting, or viewing items in the inventory.

## Configuration
- You can configure the database connection settings in the `__init__.py` file.
